# 🔔 Sistema de Notificações de Lembretes

## Como Funciona

O sistema de notificações permite que você receba alertas do navegador quando um lembrete chegar na hora marcada.

### Ativação das Notificações

1. Vá até a página de **Lembretes**
2. Clique no botão **"Ativar Notificações"** no topo da página
3. Autorize o navegador a enviar notificações
4. Pronto! As notificações estão ativas

### O que você vai receber

Quando um lembrete chegar na hora (ou até 5 minutos depois), você receberá uma notificação com:
- 🔔 "Lembrete!" como título
- O título do seu lembrete como corpo da mensagem
- A notificação permanecerá visível até você clicar nela

### Testando as Notificações

Depois de ativar as notificações, você verá um card com status "Notificações Ativas". Clique no botão **"Testar"** para receber uma notificação de teste e verificar se tudo está funcionando corretamente.

## Características

- ✅ Notificações ativas mesmo com a abinha/janela em segundo plano
- ✅ Notificações persistem na tela até você clicar (requerem interação)
- ✅ Verifica a cada minuto se há lembretes para notificar
- ✅ Evita notificações duplicadas
- ✅ Funciona em Desktop e dispositivos móveis (se o navegador suportar)
- ✅ Sincroniza com os lembretes completados automaticamente

## Requisitos

- Browser compatível (Chrome, Firefox, Edge, Opera, etc.)
- Permissão accordada para receber notificações
- Site aberto ou abinha em segundo plano

## Configurando Permissões do Navegador

Se as notificações estão desativadas ou você quer reativar:

### Chrome/Edge
1. Clique no cadeado 🔒 próximo à URL
2. Procure por "Notificações"
3. Altere para "Permitir"

### Firefox
1. Clique no menu (≡) → Preferências
2. Vá para Privacy & Security → Permissions → Notifications
3. Clique em "Manage Exceptions"
4. Encontre o site e altere para "Allow"

### Safari (macOS)
1. Abra as Preferências
2. Vá para Websites → Notifications
3. Encontre o site na lista
4. Altere para "Allow"

## Dicas de Uso

1. **Mantenha a abinha aberta**: Para melhor funcionamento, deixe a abinha do site aberta (pode estar em segundo plano)
2. **Horário Correto**: Certifique-se de que o relógio do seu dispositivo está sincronizado corretamente
3. **Múltiplos Lembretes**: Você pode receber múltiplas notificações simultâneas - cada uma aparecerá como uma notificação separada
4. **Volume do Dispositivo**: Certifique-se de que o volume das notificações está ativado nas configurações do navegador/SO
5. **Teste Primeiro**: Use o botão "Testar" para confirmar que as notificações estão funcionando antes de contar com elas

## Solução de Problemas

### Não estou recebendo notificações
- Verifique se o site tem permissão para enviar notificações
- Certifique-se de que o volume do dispositivo está ativado
- Teste usando o botão "Testar" na página de Lembretes
- Reinicie o navegador se necessário

### As notificações aparecem mas o som não toca
- Verifique o volume do seu dispositivo
- Verifique as configurações de som do navegador
- Alguns navegadores requerem que você clique na notificação para soar

### Eu mudo de aba e não vejo a notificação
- Notificações do navegador aparecem no seu centro de notificações/bandeja do SO
- Verifique seu painel de notificações do desktop/smartphone
